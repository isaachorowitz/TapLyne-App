A FEW GOOD QUESTIONS.

Before you
connect.

What do I need?+

A Mac on macOS 15+, an unlocked iPhone, and a USB data cable. Taplyne uses AssistiveTouch for Bluetooth control. Device setup also needs pymobiledevice3; the README includes the install command. The built-in agent needs Claude Code and its own login.

Does my iPhone need Developer Mode?+

The capture and input path is designed to work without Developer Mode: USB screen capture plus a Bluetooth mouse and keyboard. Nothing is installed on the phone. This is an early release, and compatibility needs testing across Mac and iPhone versions.

Where does my screen go?+

Taplyne captures the screen locally and has no cloud relay or built-in analytics. An AI agent you connect may send screenshots and text to its provider. The built-in chat uses Claude Code. You choose the agent and when it acts.

Can it type Hebrew and emoji?+

Yes, through Universal Clipboard, which needs Handoff and the same Apple Account on both devices. Taplyne checks text readback where the field supports it and stops on uncertainty. Hebrew screen recognition uses optional local OCR models.

Is it really free and open source?+

Yes. Taplyne is licensed under AGPL-3.0-only. You can read, run, and modify the source. Your AI provider may have its own charges. Taplyne is experimental and uses private macOS Bluetooth APIs, so expect device-specific rough edges.
