Give your AI a real iPhone.

TapLyne lets an AI agent see, tap, scroll and type on your iPhone. Start with a USB cable and Bluetooth, with nothing installed on the phone. Add the optional companion and encrypted remote setup for text and voice away from your Mac.

Eyes

Honest results

It tells you when it’s not sure.

Ask for an expected result and TapLyne checks the screen. Each result carries one of three statuses.

verified

It worked.

The thing you expected is on screen. Example: tap “Settings”, expect “General”. It’s there.

unverified

Maybe. Look first.

The tap went through, but the result can’t be proven yet. It checks before going on.

failed

It didn’t work.

It says so, and tells you whether the tap reached the phone at all.

Check before retrying: results report whether input reached the device. Inspect an uncertain send, purchase or submission before asking the agent to try again.

You’re in charge

Three buttons. Always there.

The AI never has the last word on your phone. You do.

PauseStops all automatic taps right now.
Take overCancels everything queued. The phone is yours.
ResumeThe AI looks again, checks what changed, then carries on.

You can resume from the Mac or paired companion. The AI’s phone tools can pause or stop, but cannot resume control.

After advanced setup, a signed runner keeps screen capture and control connected through your encrypted relay. Unplugged control and background voice passed on a physical iPad using an iPhone’s cellular hotspot.

Requires Xcode, Apple development signing, Developer Mode, and a self-hosted WSS relay. Keep the device unlocked and Mac online. Reconnect locally if the runner is killed or the device reboots. Remote setup guide.

Get started

Your first request, step by step.

Start with USB mode. The getting started guide covers the first connection, AI setup and optional remote mode.

  1. Download TapLyne and drag it to Applications.
  2. Install the USB helper with Homebrew and Terminal:brew install uv && uv tool install pymobiledevice3
  3. Plug in your iPhone, unlock it and tap Trust.
  4. Follow the setup card: allow screen capture, pair Bluetooth, turn on AssistiveTouch, calibrate.
  5. Choose your AI in Settings > Agent, then ask it to describe the screen. Use your OpenAI API key or an existing Claude Code login.

You need

  • A Mac on macOS 15 or later (Apple silicon or Intel)
  • An iPhone and a USB data cable
  • Your OpenAI API key or an existing Claude Code login
  • The phone unlocked while it works

TapLyne uses the “camera” permission only to receive the phone’s screen. It never turns on your Mac’s camera.

Questions

Good questions.

Is it really free?

Yes. TapLyne is free and open source. AI usage and optional relay hosting may cost extra.

Do I need to install anything on my iPhone?

USB mode uses the cable and Bluetooth, with no phone app. Optional remote control requires a signed runner. The text and voice companion is a separate Xcode build for iPhone and iPad.

Does it work on an Android phone?

No. TapLyne is built for iPhone and iPad.

Can the AI buy things or send messages without me?

An agent can tap Send, Buy or Submit when instructed. TapLyne does not add a universal approval screen. Review consequential actions and use Pause or Take over to stop further input; an action already delivered cannot be undone.

Why Bluetooth?

Your Mac pretends to be a mouse and keyboard. iPhone’s AssistiveTouch turns those into real taps. That is why nothing needs to be installed on the phone.

Can it type in other languages and emoji?

In USB mode, Hebrew, emoji and long text use Universal Clipboard and remain experimental. Remote mode supports exact field readback; Hebrew and emoji entry passed on a physical iPad. Fields that cannot be verified report that limitation.

Does my phone need to be unlocked?

Yes. Leave it unlocked while the AI works. TapLyne never handles your passcode or Face ID.

Is this made by Apple?

No. TapLyne is an independent project and is not affiliated with Apple.
