# Security

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/isaachorowitz/taplyne-mac/security/advisories/new). Do not publish server keys, phone identifiers, personal screenshots, clipboard contents or authentication data.

The local server can control a connected phone. Keep its API key private and its default loopback binding. Network mode requires a trusted network and protected transport. AI clients can send screen content to their providers; choose and configure those clients accordingly.

Source tests and a build do not establish safety on every device. This early release uses private macOS Bluetooth APIs. Use a test account or device for consequential workflows, inspect verification evidence, and step in when a result is uncertain.
